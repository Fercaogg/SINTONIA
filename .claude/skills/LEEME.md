# Skills de diseño de interfaces

Instrucciones para Claude sobre diseño de interfaces y animaciones (revisar animaciones, probar la interfaz con datos extremos, adaptarla al móvil, elegir bibliotecas, etc.). No forman parte de la aplicación: solo las usa Claude cuando trabaja en este repositorio.

- Origen: https://github.com/emilkowalski/skills (versión f7ce8c0, 13 de noviembre de 2026).
- Autor: Emil Kowalski. Licencia MIT (ver `LICENSE-emilkowalski-skills`).
- Se copian sin cambios. Para actualizarlas, se vuelven a copiar desde el repositorio original.

Las reglas de SINTONÍA (DISENO.md, accesibilidad WCAG 2.1 AA, movimiento reducido, sin rayas largas en la interfaz) tienen prioridad sobre estas skills.
